Production work behind

I don't just ship application code — I keep the systems it runs on healthy. Below is the kind of infrastructure work I've owned end-to-end.

Linux server patching & upgrades

Owned monthly patch cycles across a fleet of RHEL/Ubuntu hosts. Built rolling, blast-radius-aware upgrade runbooks that move workloads through dev → staging → prod with zero customer-facing downtime, including major-version OS upgrades.

140+ hosts 24/7 on-call 99.9% uptime

ELK Stack — observability

Designed Elasticsearch / Logstash / Kibana pipelines to ingest logs & metrics from app, OS and network layers. Built Kibana dashboards used by oncall to triage incidents and capacity-plan upgrades.

Beats agents Custom dashboards Retention tuned

CloudBolt orchestration

Maintained CloudBolt as the self-service portal for VM provisioning & lifecycle. Wrote blueprints and resource handlers so app teams could spin up compliant environments without touching vSphere directly.

Self-service catalog Policy-driven Audited changes

Foreman + Puppet

Used Foreman as the source of truth for host configuration, paired with Puppet classes to enforce baseline state. Smart-proxy-driven reboots, OS hardening & agent rollouts.

Smart proxies Host groups Drift-free

vSphere virtualisation

Day-to-day operation of vSphere clusters — VM provisioning, snapshot & storage policies, vMotion-aware patching. Coordinated maintenance windows with app owners.

Clusters Snapshots vMotion

AWS agent upgrades at scale

Used AWS Systems Manager (SSM) to roll out and upgrade agents — SSM, CloudWatch, ELK Beats — across EC2 fleets. Wrote SSM documents & State Manager associations so upgrades become declarative and idempotent.
